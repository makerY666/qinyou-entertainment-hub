# 牌桌体验复核 · 2026-10-03

参考范围为[雀魂官方入门手册](https://mahjongsoul.com/startguide/assets/jantama_startguide.pdf)的对局操作章节，以及[腾讯欢乐麻将官方 App Store 页面](https://apps.apple.com/cn/app/欢乐麻将/id689180123)中的对局展示。仅参考对局信息组织，不复用美术、音乐或商业运营界面。网页宣传素材不作为触控或易用性测试证据。

| 发现的问题 | 本轮处理方向 |
| --- | --- |
| 横屏手牌在窄侧栏，反复滑动才看全 | 底部全宽完整手牌，竖屏两行 |
| 本人的碰杠依附被手机隐藏的座位组件 | 独立本人副露区紧邻暗手，始终显示 |
| 手牌排序后无法确认刚摸进来的牌 | 服务端提供仅本人可见的 own_last_draw，单张分隔标注 |
| 行动提示与背景融为一体 | 持续黄铜行动条、明确轮到你及倒计时 |
| 操作缺少即时感、碰杠易漏看 | 公开事件的文字/短动画/离线语音三重提示 |
| 简单蜂鸣音没有花色、操作信息 | 中文牌名与碰杠胡音频、低音量原创音乐、独立开关 |
| 刷新或重连可能重复播放动作 | 按局与事件序号建立基线，跳过既有事件 |
| 全桌弃牌混在一起难追踪 | 按四个座位组织牌河 |
| 牌局主界面辅助入口占地过多 | 紧凑顶栏，详细规则与设置逐层展开 |

继续保留二次确认出牌、可胡时过牌确认、清晰牌纹、缺门约束提示、断线禁止提交和公开信息边界。普通按钮至少48px，横屏牌宽随整副牌适配；选中牌的大预览减少小屏辨认负担。该取舍响应本轮用户对完整牌型可见的明确要求，不宣称已完成长辈真人试用。

本轮新增资源为原创合成背景音乐及本机中文 TTS 普通提示语，运行时无网络依赖。实际验收范围与未完成项记录于 verification.md；ADB 设备授权属于操作前置条件，未经授权不能读取或控制手机。
