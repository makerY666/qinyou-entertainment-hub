# 电脑策略 v2

规则版本未改变，电脑行为升级为只接收 PlayerView 的确定性策略。没有读取真实牌墙、其他玩家暗手或隐藏暗杠牌面；公开信息相同时决策相同。

## 决策

- 优先合法胡牌。定缺比较去掉各门后的牌型距离及清缺负担。
- 枚举合法弃牌，分析四组面子一对将与七对路线，优先降低距离听牌的步数。
- 同等距离下枚举进张，按“4减本人持牌和已公开牌数”估计可用数量，优先保留有效进张更多的牌型；这些是未见牌估计，不表示牌仍在牌墙中。
- 听牌比较可用胡牌张数和本房规则下倍率，已经看尽的胡牌张不会被当成可用进张。
- 碰、暗杠、直杠、补杠先评估操作后的牌型，不再见碰就碰、见杠就杠；防止破坏七对和龙七对。
- 相近进攻价值时，依据其他未胡玩家的定缺、公开副露、已打牌和牌局进度估计放炮风险。川麻没有采用日麻振听规则，打过的牌只作为弱提示，不被宣称绝对安全。

向听/牌型距离概念参考[Mahjong deficiency研究](https://arxiv.org/abs/2108.06832)。实现为本项目的递归拆分和缓存，结合四川规则的七对四张计两对、定缺、无字牌及本项目倍率；没有直接套用日麻役种和七对限制。

## 可复现验证

`cargo test -p mahjong bot::tests --release -- --include-ignored --nocapture`

64个固定种子（2000–2063），每局1个新策略与3个旧策略，轮换新策略座位：新策略胡牌49/64、旧策略合计80/192，新策略累计+73分；1002次新策略决策，本机Windows优化构建单次最慢约10ms，总模拟约0.57秒。该组是确定性基准，不是人类对战胜率或安卓性能结论。

专项用例覆盖两面听牌取舍、拒绝破坏七对的碰、拒绝破坏龙七对的杠、四张计两对、公开进张已耗尽、定缺与已胡者的风险处理，以及隐藏手牌/牌墙顺序不影响选择。原160局随机模拟继续验证合法动作、牌张守恒、分数守恒和状态恢复。

当前为有信息边界的规则搜索策略，尚未使用自我博弈训练、对手隐手概率模型或多步蒙特卡洛搜索；后续可用更大的独立种子集合和真人对局继续评估。
