# 掼蛋扩展

绑定 [DESIGN.md](DESIGN.md)，沿用茶馆深青绿、黄铜、玉白扑克和现有Radix弹窗、48px控件、本地思源字体及150/300/500ms动效，不另起视觉风格。

四人对家布局：对家居上、对手左右、自己手牌在底部。上沿独立级牌条，避免与座位叠压。队伍名称明确显示，对家标注「对家」。玩家余牌、当前轮次和计时用已有样式。级牌标记与配牌标记位于左牌角露出范围，不因叠牌被遮挡。

27张手牌按24px最小角标露出自动分排；竖屏可分三排，不横向滚动。桌面预留自己座位宽度，避免玩家名字覆盖手牌。低横屏充分利用整幅手牌宽度，将展开入口放在操作行右侧，主操作同时可见；竖屏展开入口放在手牌区标题旁。还贡只显示服务器允许的候选牌，等待别人还贡时显示明确状态；完成还贡后恢复完整手牌。

选牌支持鼠标/触摸划选、键盘移动和空格选择，配牌有歧义时提供显式牌型选择。无效选择仍能重选，出牌按钮不发送；不出按钮仅在服务端允许时启用。断线、暂停、忙碌和非本人回合明确禁用出牌，房主可直接解除暂停。动画队列不阻塞选牌和命令；减少动画保留牌型文字。

胜负使用两队四人分数，窄屏以2×2显示；移除电脑的次要操作放进更多菜单，避免结算名次区拥挤。结算不保留巨大的空手牌区，继续按钮与成绩可直接看到。下局展示新级数、进贡、抗贡、还贡；更换座位重置升级进度。历史沿用共用控件，按四座位展示扑克和声明牌型。

验收基准：创建/入座/电脑/准备/开局/出牌/不出/接风/升级/进贡/还贡/暂停恢复/断线恢复/结算/下一局/历史回放，覆盖成功、等待、错误、无牌可压、已出完和中止。视觉检查1440×900、390×844、360×800、844×390、740×360；普通出牌时主要按钮及角标可见，没有横向溢出。声音全部离线，音乐、语音、音效独立偏好，历史事件不重播。
