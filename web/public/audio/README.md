# 离线声音资源

bgm.mp3 为本项目原创的108 BPM、32小节、约71秒立体声编曲，包含拨弦旋律、笛声回应、和弦分解、低音、鼓点和过门，采用A/B/A变化/B变化结构。无外部采样、无引用其他曲谱。可使用 scripts/generate-bgm.py（需要NumPy）重建；语音期间降低音乐音量。

voice/*.mp3 是构建时使用本机 Microsoft Huihui Desktop 中文语音生成的普通牌名和操作提示，不模拟真人身份。运行时不需要 Windows TTS、网络服务或浏览器语音包。完整生成步骤为 PowerShell 执行 scripts/generate-audio.ps1（需要 Windows 中文TTS、Python与ffmpeg）。

界面控制音乐、语音与音效开关；移动浏览器需先经用户手势解锁播放。网页隐藏或离开牌桌时停止音乐。播放失败不能影响对局。

斗地主的 `voice/ddz/` 包含 66 条离线中文语音及 `manifest.json`，涵盖单张、对子、三张、组合牌型、叫分、不出、余牌提醒、春天和胜负。使用 `scripts/generate-doudizhu-audio.ps1`（Windows 中文 TTS 与 ffmpeg）重建；生成后统一响度并裁去静音。背景音乐沿用项目原创曲目，发牌、落牌、炸弹和王炸音效由 Web Audio 合成，不依赖外部音源。

斗地主和掼蛋根据服务端公开事件逐条播放语音与动画。首次进入、断线重连、切回页面和解除暂停时跳过历史播报；暂停、离开牌桌、隐藏页面时停止播放。音乐、语音、音效分别记忆开关和音量，总静音适用于三种游戏。

掼蛋的 `voice/gd/` 包含64条离线语音与 `manifest.json`，覆盖单张、对子（含王对子）、三张、顺子/同花顺、三连对、钢板、炸弹、四大天王、进贡/还贡/抗贡、接风、头游和胜负。使用 `scripts/generate-guandan-audio.ps1` 重建，沿用相同中文TTS与响度处理。语音直接使用服务器保存的当次牌型声明，避免将玩家选择的普通顺子误报为同花顺。
