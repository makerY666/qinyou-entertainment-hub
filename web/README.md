# 亲友娱乐 Hub 网页界面

React + TypeScript + Vite，通用交互基于 Radix Dialog，动画使用 Motion。所有牌面均为本地 SVG，思源同源 Noto Sans SC / Noto Serif SC 字体随产物打包，字体许可证位于 `public/licenses`。不引用 CDN、在线字体或远程图片。

## 运行

在本目录执行 `npm ci` 与 `npm run build`。生产产物在 `dist/`，由 Rust 服务编译时嵌入。开发执行 `npm run dev`，访问 `http://localhost:5174`。Vite 的 `/api` 和 `/ws` 代理到 `127.0.0.1:18765`。后端必须先启动。

`src/api.ts` 隔离 HTTP、WebSocket、座位凭据和原生桥接。浏览器同源连接；原生客户端通过用户点击调用 `start_host`，再连接返回端口的 `127.0.0.1`。原生管理凭据单独保存在会话存储中，仅管理操作使用，绝不加入邀请链接。

## 界面范围

大厅 / 昵称 / 创建牌桌 / 入座与选座 / 四人候场 / 电脑补位 / 准备 / 定缺 / 点选确认出牌 / 碰杠胡过 / 暂停恢复 / 邀请二维码 / 实时账单 / 历史过滤与统计 / 单步回放与视角 / CSV、JSON 导出 / 明确确认删除 / 房主恢复座位 / 原生主机管理 / 提示音 / 大字 / 减少动画。

服务器提供合法动作与玩家可见状态，前端不计算输赢或预演隐藏牌。普通 HTTP 局域网不需要安全上下文：命令 ID 使用 `crypto.getRandomValues`，剪贴板不可用时选择链接供手动复制。请求使用 AbortController，避免依赖较新的 AbortSignal.timeout。
